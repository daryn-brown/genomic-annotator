    Local session SYNTHETIC DEMO
    A LOCAL-FIRST WORKSPACE

    Meet your genome.

    Open your 23andMe raw data file. We'll read the called variants and check your local annotation cache.

    It stays on this computer. No genome upload to an external service. Imports are always offline; online RSID lookup is a separate, opt-in step.
    YOU CONTROL WHAT LEAVES

    Look up public annotations

    Query MyVariant.info for distinct, uncached RSIDs in . Cached entries are reused; this is not a cache refresh.

    RSIDs can be sensitive, too.

    The service receives queried RSIDs and connection metadata, including your IP address. Your raw file, genotypes, input positions and file name are never sent.

    Lookups run in batches of 50 and may take a long time for a whole genome. You can keep browsing the previous results while the lookup runs. Do not stop the server if you want it to finish.
    TAKE YOUR RESEARCH WITH YOU

    Save a private report

    Create a standalone, searchable HTML report of all called rows in this file, including duplicates, regardless of the current filters.

    Use a new filename in an existing folder. Existing files are never replaced. New reports use owner-only permissions on macOS and Linux.

    This report contains sensitive genotype and position data. Keep it private. There are no external assets or network requests in the report.
    PRIVATE BY DESIGN

    Your data stays yours.

    01

    Local means local

    This workspace is served on 127.0.0.1, not on your network. No analytics, remote fonts, CDNs or browser storage. Imported rows live in server memory until you close the file or stop the server. Reloading the page reconnects to the same session.

    02

    Offline comes first

    Importing only consults your existing local cache. A cache miss is missing information, never a benign result. Online lookup requires explicit consent for each run and shares RSIDs plus connection metadata with MyVariant.info.

    03

    Know what remains

    Public annotations and queried RSID keys persist in the CLI's cache. Private reports persist only when you save them. Closing a tab removes its genome rows from this server, not the original file, cache or reports. This is not guaranteed secure memory or disk erasure.
    A MAP, NOT A MEDICAL ANSWER

    A new view of your data.

    Helix is the visual workspace for the local genomic annotator. Open a 23andMe raw file, explore chromosomes, and inspect public RSID annotations alongside your original calls.

    01

    Read the rings

    Each equally sized segment represents an observed chromosome. Inner bars show variant density. Positions are normalized to that chromosome's maximum observed input position, not reference chromosome lengths. Colors distinguish chromosomes, not health or risk.

    02

    Follow a variant

    Click a chromosome to filter the browser. Select a row to place it on the map and open its inspector. Search and classification/status filters intersect. Rows stay in input order, including duplicates. Genotype letters are calls, not a reconstructed DNA sequence.

    Research only. Not diagnostic.

    An RSID can describe multiple alleles with different interpretations. This tool does not match your genotype, strand or reference build to an annotated allele. Do not infer disease, personal risk, carrier status or treatment decisions. Personal medical conclusions require allele-aware clinical confirmation.
